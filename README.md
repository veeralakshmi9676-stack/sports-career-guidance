Sports Career Guidance System

About the Project

SportPath is a web-based application that helps students explore sports, career opportunities, academies, scholarships, and academic guidance.

Technologies Used

- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: Python, Flask
- Database: MySQL

Features

- User Registration and Login
- Sports Information
- Career and Academic Guidance
- Sports Academies and Scholarships
- Sports News
- Profile Management

Objective

To guide students and aspiring athletes in exploring sports-related career opportunities.
